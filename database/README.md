# database/

本目录预留给未来的业务数据库资产（schema、迁移脚本、初始化数据等）集中存放，当前**为空**（只有本说明文件）。

## 当前数据边界（截至 2026-11-05）

- **没有业务 SQL、没有 ORM、没有数据库**。后端不连任何数据库；行程规划核心是纯函数 + 外部服务（高德 / Open-Meteo / Tavily / OSM）。
- 浏览器端数据（行程、编辑草稿、费用草稿、本机工作进度恢复）存放在**浏览器 localStorage**，不上传、不进后端、不跨设备同步；容量与结构约束见 `docs/` 相应文档。
- `outputs/`（仓库根）是 write_server 的**文件导出目录**（行程 Markdown 等），属于导出产物，不是数据库。
- 本目录不引入 `.codegraph/`（本地工具索引）或任何仓库外记忆库；也不会为"看起来完整"而新增空的 schema/迁移占位文件。

后续若引入真实持久化（如 SQLite/Postgres），schema、迁移与说明放本目录，并在本文档更新边界。
