# 手动费用估算与预算提醒

日期：2026-11-01。对应分支 `feat/interactive-travel-planner`，前置基线 `3c96180`。

## 这是什么

行程区里新增一个「费用估算」入口：用户手动填写各项费用，页面算出已知合计、分类小计，并与用户自己填的总预算做保守比较。它是整趟 Trip 级的手动工具，不接 AI、不接真实价格。

## 诚实边界（先读这个）

- **金额全部手填**：不查询真实价格、库存或汇率，不从模型输出、POI 原文或讲解里猜金额，不把费用发给 AI 当规划约束。名称和金额都是用户自己的记录，不是任何服务提供者的报价。
- **CNY 是固定输入单位**：不是按目的地推断的当地币种，不换汇；金额按整项总费用填写，不按人数或天数自动乘算。
- **合计只算已填合法金额，实际花费未知**：未填、无效和未记录的费用不计入，合计可能高于也可能低于实际花费；不超过预算只说明「已填部分未超」，不能据此认为整趟行程在预算内、可以支付或可以预订。超预算时明确说「已填部分已超」，同时提醒未计入项。
- **只有点「计算已填费用」才产生结果**：任何输入、增删、清空、撤销、沿用、新建都会作废旧结果，须重新计算。旧结论不挂新输入。
- **0 合法、空白未填、无效不当 0**：留空表示这笔费用未知，不会按 0 计入；错误输入保留原字符串、给固定文案，不四舍五入、不截断、不悄悄改写。
- **只在本页内存**：费用草稿不随行程保存或导出，不写 localStorage，刷新页面会丢失。界面有固定说明。
- **快照不可验证时 fail closed**：行程内容无法序列化时，费用草稿整体锁定，不能编辑、沿用或计算；固定提示，不回显异常原文。

## 钱的表示

金额按普通十进制字符串精确拆分为整数分：整数部分与小数部分分开转数字、小数位补足分位后相加。不做 `Number(raw) * 100` 这类浮点乘法——`0.10 + 0.20` 精确等于 `0.30`。格式化从整数分生成两位小数。接受 `128`、`12.5`、`0`；拒绝负数、正负号、科学计数法、千分位、全角数字、多于 2 位小数、超过上限的值。上限：最多 32 项；单项金额与整趟总预算最大 `99999999.99` 元。32 项上限使总和远小于 `MAX_SAFE_INTEGER`，求和仍逐项做安全整数检查。

## 归属（owner）与保留输入

费用草稿属于明确的 **Trip id + 统一 revision（复用 App 的 `tripRevision`）+ 内容快照（序列化串）** 三元组，三者必须同时匹配；不能只比 id 或对象引用。

- 行程变化（规划、恢复、导入、本地应用、AI/地图应用、撤销应用）后，旧费用草稿**只读保留**：金额可查看，不能在新版本上编辑或计算，也不显示旧结果当新结果。
- 只有用户显式点「沿用这份费用到当前行程」（复制用户输入、重新绑定 owner、清结果）或「新建当前行程费用草稿」（清空并可一次撤销），才对当前版本继续。A→B→A 来回切换后沿用产生的是新绑定，不会悄悄复活与旧版本的已确认关系。
- 快照序列化失败（循环引用、BigInt 等被改写过的宿主对象）不能建立可验证归属，此时禁止编辑、绑定与计算；不能用固定失败字符串冒充有效匹配。

## 操作与撤销

新增、删除、清空、字段编辑（分类、名称、金额）、预算输入、沿用、新建全部费用操作各保留一层撤销（内存内一层，快照不含 undo 自身，不递归，也不越过行程版本：owner 失配或快照不可验证时拒绝撤销）。预算操作不动原 Trip、地图、讲解、保存、JSON/ICS/Markdown 导出，也不影响原 Trip 自己的撤销链。显式收起面板后焦点回到「费用估算」入口按钮，隐式隐藏（编辑 / AI / 地图打开）不抢焦点。`editingDraft` / `aiOpen` / `mapOpen` 期间费用入口收起，`interactionPaused` 边界不变。

公共计算入口对结构约束做显式校验：超过 32 项、行 id 缺失或重复、分类非法、字段非文本都会以 typed 错误拒绝整次计算，不把异常输入冒充「没有合法金额」或合计 0；上限内求和不可能溢出，溢出分支只防御内部不变量被破坏。

## 设计

Extension 模式：沿用现有宣纸/朱砂 tokens（`tokens.css`），样式限定 `.tbg-` 前缀，不写死色值，不改全局 tokens 或 `app.css`。默认收起；44px 触达、明确 label、`focus-visible`、单一 `aria-live` 播报区；条目在 720px / 400px 以下逐级堆叠，不撑横向页面。文本全部 React 文本节点渲染，不使用 `dangerouslySetInnerHTML`。

## 未做与局限

- 未做真实浏览器验收；完整前端 suite 与 CI 结果以推送后的实际运行为本。
- 不做持久化：刷新丢失是设计行为，本批不新增任何自动或独立存储。
- 不接后端：没有预算 API，后端规划不受这些填写值影响。
- 金额不自动乘算人数/天数，也不提供币种切换。
